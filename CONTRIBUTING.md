# Contributing

Thanks for your interest in TrainingLoop!

- **Bug reports and ideas** are welcome in [GitHub Issues](https://github.com/PersonaN1/TrainingLoop/issues) or in the Telegram channel [@setnewloop](https://t.me/setnewloop).
- **Pull requests from outside contributors are not accepted.** TrainingLoop is not open source (see [LICENSE](LICENSE)), so please describe the change in an issue instead of sending code.
