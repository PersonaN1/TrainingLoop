# 0002. Код SetLoop копируется, а не выносится в общий пакет

Дата: 2026-10-16. Статус: принято (пользователь выбрал вариант А).

## Контекст

TrainingLoop переиспользует около трети кода SetLoop: синтез звуков, аудиосессию, голос, вибрацию, Live Activity, настройки, компоненты. Два пути: скопировать файлы или вынести их в общий Swift Package в отдельном репозитории.

## Решение

Копируем. После переноса файлы развиваются в каждом приложении независимо.

## Альтернативы

- **Общий пакет (`LoopKit`)**: одна правка на оба приложения, но третий репозиторий, версии и риск, что правка под TrainingLoop незаметно сломает SetLoop. Логика таймера у приложений разная (шаги vs отдых и «Выполнено»), общий код ещё не устоялся.

## Последствия

- Баг в общем коде чинится в двух местах; при правке в одном приложении стоит проверить, есть ли тот же код в другом.
- Если через время скопированный код перестанет меняться — вынести его в пакет; это проще, чем обратный путь.
