# TrainingLoop (iOS) — спецификация

> Документ заполняется по ходу обсуждения: сюда попадают только подтверждённые решения.

## Исходные требования

0. Название TrainingLoop. Максимально близко к SetLoop: дизайн-концепт, код и стиль можно переиспользовать. Те же принципы: без регистрации, без платных функций, без сбора данных.
1. Составление тренировки заранее (механизм, похожий на конструктор SetLoop).
2. Упражнения: базовые (встроенные, 30–40 шт.) и пользовательские.
3. Упражнение выполняется на количество или на время. Для упражнений с отягощением задаётся вес (подтягивания с весом, приседания и т. п.). Таймер для упражнений на время — возможно, отдельная фича позже.
4. Два способа тренироваться: по заранее составленному набору или свободно, добавляя упражнения по ходу. Можно разнести по экранам/вкладкам. Выполненная тренировка в любом случае сохраняется в историю.
5. **Важно:** статистика по выполненным тренировкам — прогресс отдельного упражнения (например, месяц приседаний) и общий прогресс (тоннаж, длительность, виды упражнений, число подходов и т. п.).
6. Выгрузка тренировок (текст, таблица — решить), чтобы согласовать программу с тренером. В будущем — загрузка программы от тренера.

## Принятые решения

- **D1. Шаблон, а не программа.** В v1 пользователь составляет **шаблоны** — планы одной тренировки. Многодневные **программы** с расписанием (дни A/B, недели) — позже; термин «Программа» зарезервирован за ними (см. CONTEXT.md).
- **D2. Упражнение описывается атрибутами, а не жёстким типом.**
  - Мера: «Повторы» или «Время», ровно одна. В v1 только эти две; позже можно добавить (например, «Дистанция» для кардио). Повторы и время одновременно не бывают.
  - Отягощение: да / нет. Если да — в подходе есть поле веса, его можно оставить пустым (подтягивания без пояса). Если нет — поля веса нет. Вес — дополнительное отягощение; собственный вес тела в тоннаж не входит. Статистика считается по фактически записанному весу. (Изначально было три режима — нет / по желанию / обязательно; упрощено до двух, т. к. «обязательно» влияло только на проверку ввода.)
  - Описательные атрибуты: название, оборудование (Собственный вес, Штанга, Гантели, Гири, Тренажёр, Блок, Резина, Другое), группы мышц, заметка. На учёт не влияют, служат для поиска и фильтра.
  - Меру нельзя изменить после первой записи упражнения в историю; отягощение — можно.
  - «Подтягивания с весом» — не отдельное упражнение, а «Подтягивания» с заполненным весом.
- **D3. Суперсеты в v1.** Соседние упражнения шаблона выделяются и объединяются кнопкой «Объединить в суперсет» (как «Объединить в блок» в SetLoop). Выполняются по кругу: по одному подходу каждого упражнения. Вложенных нет. При разном числе подходов в последних кругах участвуют только упражнения с оставшимися подходами. Термин «сет» не используется (см. CONTEXT.md).
- **D4. Подходы в шаблоне — списком.** У каждого подхода своя строка (повторы или время, вес). «+ Подход» копирует предыдущую строку. Так описываются пирамиды и разминочные подходы. Вес в шаблоне необязателен: если не задан, при выполнении подставляется вес из прошлого раза.
- **D5. Таймер отдыха в v1.**
  - Отдых задаётся у упражнения в шаблоне; значение по умолчанию — в Настройках (например, 1:30).
  - У суперсета два значения: между упражнениями внутри круга и после круга.
  - Запускается автоматически, когда подход отмечен выполненным.
  - Во время отдыха: оставшееся время, кнопки «+10 с», «−10 с», «Пропустить».
  - Сигнал за 3 с до конца и в конце, вибрация, Live Activity и работа в фоне — как в SetLoop.
  - Если приложение не может подать сигнал на экране блокировки (звуки и голос выключены или беззвучный режим не игнорируется), конец отдыха приходит уведомлением «Отдых окончен» с текстом «Далее: …». Разрешение на уведомления спрашивается при первом таком отдыхе.
  - Фактический отдых в историю не сохраняется.
  - Таймер выполнения подхода «на время» — отдельная функция, отложена.
  - На экране блокировки (Live Activity) — две плашки: отдых (+10, Пропустить) и текущий подход с кнопкой «Выполнено», которая отмечает подход подставленными значениями и запускает отдых (DESIGN V11).
- **D6. Тренировка по шаблону и свободная.**
  - Тренировка по шаблону стартует с копии шаблона; свободная — пустой. Других отличий нет.
  - Во время тренировки можно всё: добавить/удалить упражнения и подходы, менять порядок, править значения, «Заменить» упражнение другим из каталога. Шаблон при этом не меняется.
  - Если состав (упражнения, подходы) отличался от шаблона, на экране итогов есть переключатель «Обновить шаблон», по умолчанию выкл. Изменения веса и повторов не учитываются.
  - Свободную тренировку на экране итогов можно «Сохранить как шаблон».
- **D7. Ввод подходов и «прошлый раз».**
  - У строки подхода: колонка «Прошлый раз», поля (вес, повторы/время), галочка.
  - «Прошлый раз» — последняя тренировка с этим упражнением, по любому шаблону; подходы сопоставляются по номеру.
  - Поля заполняются: значение из шаблона → иначе из «прошлого раза» → иначе пусто. Подставленное показано серым; галочка без правок принимает его.
  - Неотмеченные подходы при завершении не сохраняются.
- **D8. Каталог упражнений.**
  - Встроенные (30–40, RU + EN): название, мера и отягощение не меняются. Можно скрыть (вернуть — в Настройках), дублировать в своё, вести заметку.
  - Свои: редактируется всё, кроме меры после первой записи в историю. Удаление: если нет в истории — сразу; если есть — в архив (не видно в каталоге, история и статистика сохранены, можно вернуть).
  - Названия упражнений уникальны.
  - Лимиты: 1000 своих упражнений, 100 шаблонов; при достижении — подсказка, как в SetLoop.
- **D9. Группы мышц.** Фиксированный список из 14: Грудь, Спина, Трапеции, Шея, Плечи, Бицепс, Трицепс, Предплечья, Пресс, Квадрицепсы, Бицепс бедра, Ягодицы, Икры, Всё тело. У упражнения одна основная группа (обязательно) и вспомогательные (по желанию, только описание). Статистика по группам считается только по основной.
- **D10. Статистика упражнения.**
  - Графики по тренировкам, периоды месяц / 3 мес / год / всё: лучший вес (по умолчанию, реальный), тоннаж; без веса — макс. и сумма повторов; на время — макс. время.
  - Рекорды: вес, повторы, тоннаж за тренировку, лучший вес на 1/3/5/8/10 повторов. Расчётный 1ПМ (Эпли, подходы до 12 повторов) — только справочная плитка с пояснением, без графика и без 🏆.
  - Список тренировок с этим упражнением и его подходами.
  - Новый рекорд отмечается 🏆 у подхода во время тренировки и перечисляется на экране итогов.
  - У расчётного 1ПМ пояснение по ⓘ (DESIGN V7).
- **D11. Общая статистика.**
  - Итоги тренировки: длительность, тоннаж, число упражнений / подходов / повторов, новые рекорды, подходы по группам мышц.
  - Сводка за неделю / месяц / год: число тренировок, общее время, тоннаж и подходы (график по неделям), распределение подходов по группам мышц, календарь дней тренировок, серия недель подряд.
  - Не в v1: калории, карта тела, сравнение периодов.
- **D12. Выгрузка — текстом через «Поделиться».** Шаблон, тренировка или тренировки за период превращаются в читаемый текст для мессенджера (упражнения, подходы, суперсеты, итоги). Таблица CSV и импорт программы от тренера — позже.
- **D13. Навигация.** Вкладки «Тренировки · История · Упражнения · Настройки».
  - Тренировки: кнопка «Начать свободную тренировку» и список шаблонов (как список таймеров SetLoop: карточки, ▶, перетаскивание, массовое удаление).
  - История: переключатель «Записи / Сводка» (сводка — D11).
  - Упражнения: каталог с поиском и фильтрами (группа мышц, оборудование); тап — статистика упражнения (D10).
  - Идущая тренировка сворачивается в плашку над вкладками; одновременно идёт только одна.
- **D14. Наследуется из SetLoop** (см. SetLoop/docs/SPEC.md, TECH.md): iOS 17+, только iPhone с заделом на iPad (D8); бесплатно, без рекламы, без регистрации, «Data Not Collected» (D11); RU + EN, встроенные упражнения тоже на двух языках (D12); модель совместима с iCloud, синхронизация в v1.1 (D13); Apple Health в v1.1 как «Силовая тренировка», Watch позже (D14); тема и доступность (D17); privacy/support на GitHub Pages (D20); стек SwiftUI + SwiftData + XcodeGen + CI, звук и Live Activity переносятся из SetLoop.
- **D15. Единицы, ввод и ограничения.**
  - Единицы — настройка «кг / фунты», по умолчанию кг. Одна на всё приложение; при смене история пересчитывается для отображения без потерь. Смешивать единицы внутри упражнения нельзя.
  - Вес вводится цифровой клавиатурой с дробной частью, точность 0,25 (кг или фунта). Кнопок «±2,5» нет.
  - Диапазоны: вес 0–999,75 кг (в фунтах — эквивалент); повторы 1–999; время 1 с – 59:59.
  - Длина текста: названия (упражнение, шаблон, тренировка) — до 60 символов, как в SetLoop; заметки и описания — до 1000 символов.
- **D16. История.**
  - Запись не зависит от шаблона: правка или удаление шаблона её не меняет; «Повторить» работает и после удаления шаблона.
  - Хранится: дата и время начала, длительность, название (из шаблона или «Свободная тренировка»), заметка, упражнения, суперсеты, выполненные подходы.
  - Запись можно редактировать задним числом (значения, подходы, упражнения); рекорды и статистика пересчитываются.
  - Тренировку можно добавить вручную задним числом.
  - Лимит 3000 записей. С 2900 вверху «Истории» плашка «Осталось N мест: удалите старые записи или выгрузите их текстом». На 3000 экран итогов сохраняет только с удалением самой старой записи и явно называет её («Будет удалена тренировка от …»). Молча ничего не удаляется.
- **D17. Встроенные упражнения — 53 шт.** Список, группы, оборудование, мера и отягощение — docs/EXERCISES.md. Классика любого зала плюс по 1–2 на каждую группу мышц и несколько без железа; узкие вариации пользователь добавляет как свои.
- **D18. Первый запуск.** Отдельного онбординга нет; вместо него 3 шаблона-примера: «Фулбади» (присед, жим лёжа, тяга в наклоне, жим стоя, планка; без весов), «Ноги + подтягивания» (суперсет присед ↔ подтягивания ×4, отдых 30 с / 90 с, затем румынская тяга), «Дома без железа» (суперсет отжимания, приседания без веса, скручивания, бёрпи ×3, затем планка). Примеры редактируются, удаляются и считаются в лимит. Пустая история — подсказка «Начните тренировку — она появится здесь».
- **D19. Длительность и незавершённая тренировка.**
  - Паузы у тренировки нет; длительность — от «Начать» до «Завершить». Пауза есть только у таймера отдыха.
  - Идущая тренировка сохраняется после каждого действия и восстанавливается после закрытия приложения, разряда или выгрузки iOS.
  - Если с последней отметки подхода прошло больше 2 часов, при открытии — вопрос «Тренировка ещё идёт? Продолжить / Завершить». При «Завершить» длительность считается до последней отметки.
  - Длительность можно исправить вручную в записи истории.
- **D20. Настройки.**
  - Тренировка: единицы (кг / фунты), отдых по умолчанию (1:30), автозапуск таймера отдыха (вкл).
  - Звук и отклик: набор звуков (есть «Выкл»), вибрация, игнорировать беззвучный режим, голос («Отдых окончен», «3-2-1»; по умолчанию выкл).
  - Экран: показ на экране блокировки, не гасить экран во время тренировки, тема.
  - Упражнения: скрытые встроенные, архив своих.
  - Ссылки «Конфиденциальность» и «Поддержка».
  - «Паузы при звонке» нет: отдых — реальное время; во время звонка сигналы не воспроизводятся.
- **D21. Название: TrainingLoop.** Общее для RU и EN, в паре с SetLoop. На 2026-10-15 в App Store (US, RU) приложения с таким названием нет (есть «Train Loop»); окончательно проверить при резервировании в App Store Connect.
  - Удаление свайпом или массово — с подтверждением.
- **D22. Поддержка — общий Telegram @setnewloop** с SetLoop, плюс GitHub Issues TrainingLoop. Страницы privacy/support и главная — на GitHub Pages из `site/`.
