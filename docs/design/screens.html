Макеты TrainingLoop

Экраны первой версии по решениям V1–V12 из docs/DESIGN.md. Каждый экран показан в светлой и тёмной теме; длинные экраны прокручиваются внутри телефона.

Тренировки

Вкладка с шаблонами, предпросмотр и редактор. Шаблоны «Ноги + подтягивания», «Фулбади» и «Дома без железа» — примеры первого запуска (D18).

V5 · D13Карточки шаблонов

Состав до 6 строк и «…ещё N», ▶ — сразу старт. Над таб-баром — свёрнутая идущая тренировка.

V6Предпросмотр шаблона

Состав только для чтения, «Старт» закреплён внизу, ✎ и ⋯ вверху.

V6 · D3 · D4Редактор шаблона

Лист. Суперсет — секция с морской полосой и двумя строками отдыха. Пустой вес — серым «прошлый».

Идущая тренировка

Один список: текущее упражнение раскрыто, выполненные свёрнуты. Отдых — панель внизу, тап разворачивает его на весь экран.

V3 · D7Подходы и «Прошлый раз»

Выполненные упражнения свёрнуты. Значения подставлены из шаблона и прошлого раза (серым), галочка сохраняет подход.

V4 · D5Суперсет и отдых

Подсветка на следующем подходе переходит между упражнениями по кругу. Отдых внутри круга — 0:30.

V3Отдых на весь экран

Зелёный экран в стиле SetLoop: кольцо, −10 / Пропустить / +10, что дальше.

V8 · D6Итоги тренировки

Рекорды текстом тёмного коралла, «Обновить шаблон» выключен по умолчанию, «Не сохранять» с подтверждением.

История

Записи по дням и сводка за период.

V9 · D16Записи

🏆 N справа, «начало · длительность · тоннаж», упражнения одной строкой с «+N».

V9 · D11Сводка

Плитки, тоннаж по неделям, календарь месяца, подходы по группам мышц: топ-3 и «ещё N».

Упражнения

Каталог из 53 встроенных и своих упражнений, форма нового упражнения и статистика.

V10 · D8Каталог с фильтром

Текстовая кнопка «Фильтр (1) ▾», чип «Спина ✕» под поиском, бейдж «своё».

V10Меню фильтра

Группа мышц, оборудование, «Только свои».

V10 · D2Новое упражнение

«Тип упражнения» со значением справа и тумблер «С отягощением» оформлены одинаково.

V7 · D10Статистика упражнения

График веса с рекордами кораллом, плитки, лучший вес на 1/3/5/8/10 повторов, история.

V7Что такое расчётный 1ПМ

Лист по ⓘ: формула Эпли с примером, «это прогноз, а не поднятый вес».
